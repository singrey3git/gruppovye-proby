# Групповые пробы

Преподаватель вводит своё имя и сразу получает ссылку для детей. Дети открывают ссылку, вводят имя и дату рождения и сразу начинают пробы. Преподаватель видит карту прохождений в реальном времени: кто подключился, сколько ему лет, на какой он пробе, сколько линий прошёл, где был тупик, с какой попытки проба пройдена. Дети этой карты не видят.

Тесты в линейке идут по порядку:

1. «Одним росчерком»: 6 проб (image 18, 14, 21, 16, 23, 22) и, по желанию, обучение из двух фигур.
2. «Закономерности»: 6 заданий, в каждом нужно выбрать один вариант из пяти. Правильные ответы слева направо: 5, 3, 2, 2, 3, 1.
3. «Части фигуры»: 6 заданий, нужно отметить три части из шести, из которых складывается фигура. «Ответить» нажимается, только когда выбрано ровно три. Верно, только если выбраны все три правильные. Правильные: 3-5-6, 1-3-5, 2-4-6, 3-4-6, 1-3-4, 3-4-5 (номера слева направо, сверху вниз).
4. «Развёртка куба»: 6 заданий, по развёртке выбрать один кубик из трёх. Правильные: a, b, a, a, c, c.

Пока идут тесты, ребёнок не видит, верно ли ответил. Над заданиями у него полоска «Тест 1 из 4» с названиями тестов: видно, где он, но переключаться между тестами нельзя.

## Этапы

1. **1-й этап.** Ребёнок проходит тесты по порядку. Закончив, видит «Подожди, преподаватель скоро покажет результаты».
2. **Результаты.** Преподаватель нажимает «Показать результаты» у ребёнка (или «Показать результаты закончившим» для всех сразу). Ребёнок видит, сколько верно, и карту: каждое задание зелёное или красное.
3. **2-й этап.** Преподаватель нажимает «Открыть 2-й этап». Ребёнок может открыть любое задание любого теста, красное или зелёное, и решить его ещё раз, а потом вернуться к карте.

## Карта у преподавателя

Строки — задания, сгруппированные по тестам, внизу каждого теста итог. Столбцы — дети, у каждого два столбца: «1-й этап» и «2-й этап». Во втором видно, какое задание ребёнок сейчас перерешивает и с каким результатом; в итоге показано, сколько стало верных и на сколько изменилось.

Нажатие на название задания открывает саму пробу (фигуру, задание и варианты с отмеченным правильным). Нажатие на клетку ребёнка показывает ещё и его результат, с переключателем «1-й этап / 2-й этап».

## Демо-режим

Пока `js/config.js` пустой, всё хранится в одном браузере. Проверить можно двумя способами:

- открыть ссылку для детей в соседней вкладке того же браузера (можно несколько вкладок, каждая будет отдельным ребёнком);
- нажать «Пройти как ребёнок»: экран ребёнка откроется справа на той же странице, кнопка «+ ещё» добавляет второго.

Локально достаточно открыть `index.html` двойным кликом.

## Подключение Supabase (чтобы дети заходили со своих устройств)

1. Создайте проект на supabase.com.
2. SQL Editor → New query → вставьте содержимое `supabase.sql` → Run. (Если вы уже запускали его раньше, запустите ещё раз: он добавит этапы и ничего не сломает.)
3. Authentication → Sign In / Providers: включите «Allow anonymous sign-ins». Преподаватель входит только по имени, без почты и пароля. Его запуски привязаны к браузеру, в котором он вошёл: с другого компьютера он попадёт в новое пустое пространство.
4. Project Settings → API: скопируйте Project URL и publishable (anon) key в `js/config.js`.

Ключ из пункта 4 публичный, его можно хранить на GitHub: доступ к данным ограничен правилами в `supabase.sql`. Преподаватель видит только свои запуски, дети могут только войти в открытый запуск и записывать свои ходы.

## Что записывается

Для каждой пробы: результат (пройдена или пропущена), число попыток, неудачные попытки (тупик или «начать заново») с числом пройденных линий, время, время до первого хода (планирование), число отмен хода. Кнопка «Скопировать для Excel» на странице сессии выдаёт таблицу по всей группе; строки 2-го этапа отмечены в столбце «Этап».

Если ребёнок обновит или закроет страницу, при повторном открытии ссылки он вернётся туда же: на следующую непройденную пробу, к результатам или к карте 2-го этапа.

Каждому ребёнку при входе выдаётся номер из 4 цифр (виден ребёнку на экране и преподавателю в шапке столбца). Если ребёнок открыл ссылку на другом устройстве или в браузере стёрлись данные, он вводит этот номер под формой входа и продолжает с того же места. По номеру можно вернуться, даже когда вход для новых участников закрыт.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий и загрузите в него содержимое этой папки (файл `index.html` должен лежать в корне).
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
3. Через 1–2 минуты страница откроется по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
